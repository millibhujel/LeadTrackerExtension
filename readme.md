     Chrome Extension

A simple Chrome extension built as part of my learning journey through Scrimba's Full-Stack Web Development course. This project helped me practice JavaScript and learn how to build interactive browser extensions.

   ##Features
Save and manage useful links.
Interact with browser tabs.
Simple and user-friendly interface.
Built using fundamental web development technologies.
🛠️ Technologies Used
HTML5
CSS3
JavaScript

    ##Installation and Usage
Clone this repository:
git clone YOUR_REPOSITORY_URL

Open Google Chrome and navigate to chrome://extensions/.
Enable Developer mode.
Click Load unpacked.
Select the project folder.
Click the extension icon to start using it.
